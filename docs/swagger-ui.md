`http://localhost:8080/swagger-ui/index.html` es la **interfaz gráfica de Swagger/OpenAPI** que tu aplicación Spring Boot expone.

Sirve para:

* 📖 **Documentar automáticamente** todos tus endpoints REST (métodos GET, POST, PUT, DELETE).
* 🧪 **Probar endpoints** desde el navegador sin usar Postman o curl.
* 🔑 **Integrar seguridad** (por ejemplo, botón *Authorize* con JWT).

Es una **UI interactiva** generada por Swagger para visualizar y testear tu API. 🚀
